# Медновости РК

Автоматическая RSS-лента новостей здравоохранения Казахстана: лабораторная диагностика и анализаторы,
стройки и открытия больниц, переоснащение и закупки, приказы МЗ РК, медицинские изделия.

Сборщик запускается на GitHub Actions каждые 3 часа, отбирает новости по ключевым словам и
публикует ленты в `docs/` (GitHub Pages).

## Просмотр и избранное

Страница https://sagynrus.github.io/med-news-kz/ показывает все новости за 30 дней:
сортировка по важности или дате, фильтр по рубрике, источнику и периоду, поиск,
звёздочка ☆ сохраняет новость в «Избранное» (в этом браузере) с заметкой.
Избранное можно скачать файлом JSON и загрузить на другом устройстве.

Важность = вес рубрики (`weight` в `config/keywords.yaml`) + по баллу за каждое найденное ключевое слово.
Данные страницы: `news.json` (обновляется вместе с лентами). Шаблон страницы: `collector/viewer.html`.

## Ленты

| Лента | Файл |
|---|---|
| Все рубрики | `feed.xml` |
| Лабораторная диагностика и анализаторы | `lab.xml` |
| Стройки, запуски и открытия больниц | `build.xml` |
| Переоснащение, закупки и поставки | `supply.xml` |
| Приказы, законодательство, Минздрав | `law.xml` |
| Медицинские изделия и регистрация | `devices.xml` |

Адрес: `https://sagynrus.github.io/med-news-kz/<файл>`

## Как править

- Источники: `config/sources.yaml`
- Рубрики и ключевые слова: `config/keywords.yaml` (`*` = любое окончание)
- Instagram: см. [INSTAGRAM.md](INSTAGRAM.md)

После правки сборщик запускается сам. Запустить вручную: вкладка Actions → «Сбор новостей» → Run workflow.
Отчёт по каждому источнику виден в логе запуска.
