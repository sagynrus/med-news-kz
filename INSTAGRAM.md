# Подключение постов Instagram

Сборщик читает публичные посты бизнес-аккаунтов (например, @turarhealthcare, @kazmedtech)
через официальную функцию Instagram API **Business Discovery**. Сторис так получить нельзя.

Для этого нужен **ваш** Instagram-аккаунт в режиме «Бизнес», привязанный к странице Facebook.
Настройка разовая, около 30 минут.

## 1. Бизнес-аккаунт Instagram и страница Facebook

1. В приложении Instagram: Настройки → «Тип аккаунта и инструменты» → «Переключиться на профессиональный аккаунт» → «Бизнес».
   Подойдёт новый пустой аккаунт, публиковать в нём ничего не нужно.
2. Создайте страницу Facebook (facebook.com/pages/create), если её нет. Название любое.
3. В настройках страницы Facebook: «Связанные аккаунты» → Instagram → войдите в этот бизнес-аккаунт.

## 2. Приложение в Meta for Developers

1. Откройте developers.facebook.com, войдите тем же аккаунтом Facebook, нажмите «Мои приложения» → «Создать приложение».
2. Тип или сценарий использования выберите «Другое» → «Бизнес» (названия пунктов у Meta иногда меняются: нужен вариант с доступом к Instagram Graph API / Pages).
3. Название приложения любое, например `med-news-kz`. Публиковать приложение (Live mode) не нужно.

## 3. Токен и ID

1. Откройте Graph API Explorer: developers.facebook.com/tools/explorer
2. Справа выберите ваше приложение. Нажмите «Generate Access Token» и отметьте разрешения:
   `instagram_basic`, `pages_show_list`, `pages_read_engagement`, `business_management`.
   Подтвердите доступ к вашей странице и Instagram-аккаунту.
3. Сделайте токен долгоживущим: нажмите на значок «i» рядом с токеном → «Open in Access Token Tool» → «Extend Access Token».
   Скопируйте новый токен и вставьте его обратно в поле токена в Explorer.
4. В строке запроса выполните `me/accounts`. В ответе найдите вашу страницу и скопируйте:
   - `access_token` страницы — это **IG_TOKEN** (такой токен страницы не истекает);
   - `id` страницы.
5. Выполните запрос `<id страницы>?fields=instagram_business_account`.
   Число в `instagram_business_account.id` — это **IG_USER_ID**.

## 4. Секреты в GitHub

Репозиторий med-news-kz → Settings → Secrets and variables → Actions → «New repository secret»:

- `IG_USER_ID` — число из шага 3.5
- `IG_TOKEN` — токен страницы из шага 3.4

**Токен никому не пересылайте, в том числе в чат.** Он нужен только в секретах GitHub.

## Проверка

Вкладка Actions → «Сбор новостей» → Run workflow. В логе должны появиться строки
`ok  Turar Healthcare (Instagram): получено …`. Если там ошибка, пришлите её текст (без токена).

Добавить другой аккаунт: допишите его в `config/sources.yaml` по образцу. Это должен быть
бизнес- или авторский аккаунт, личные аккаунты API не отдаёт.
